# Standalone Review Document Index

Use this as `docs/0000_DOCUMENT_INDEX.md` only when the project creates numbered standalone review reports.

| ID | Filename | Status | Summary |
|---|---|---|---|
| DOC-0001 | `0001_REVIEW_EXAMPLE.md` | FINAL | Example standalone review |

Rules:

- Allocate the next unused four-digit number for `NNNN_REVIEW_SCOPE.md`.
- Do not reuse numbers.
- Do not apply this sequence to specifications, plans, architecture documents, policies, or handoff files.
- Keep actionable findings in the stable `docs/review-findings.md` ledger with independent `RVW-###` IDs.
- Keep dates, scope, status, and verification evidence inside the review report.
