# L3 Decision Session

```text
SESSION AUTHORIZATION
Role: DECISION
Maximum authorized level: L3
Decision scope: <one explicit architecture/interface/schema/domain question>

Resolve only the named decision using authoritative specifications, project rules, relevant code, and evidence.

Output:
- Decision
- Evidence and authority
- Constraints that implementation must preserve
- Required implementation behavior
- Acceptance criteria
- Remaining uncertainty

Do not broaden into unrelated implementation. If authority or evidence is insufficient, return NEEDS-CLARIFICATION instead of inventing semantics.
```
